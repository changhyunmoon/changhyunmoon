꾸준히 성장하는 백엔드 개발자 문창현입니다.
Java와 Spring을 중심으로 서비스를 개발하며, 화면 구현부터 배포·운영까지 경험을 넓혀가고 있습니다.

## Selected Projects

### [Dondok (돈독)](https://github.com/prgrms-aibe-devcourse/AIBE5_FinalProject_OIT_BE) · 인프라 및 배포

보증금과 미션 인증을 결합한 습관 형성 플랫폼입니다.

- AWS EC2에서 Docker로 서버를 운영하고, RDS(MySQL)에 서비스 데이터를, S3에 인증 사진을 저장합니다.
- GitHub Actions로 배포를 자동화하고, Nginx로 Blue/Green 환경 간 트래픽을 전환합니다. Prometheus와 Grafana로 서비스 상태를 모니터링합니다.

### [UNIBUSK](https://github.com/SWYP12-UNIBUSK/unibusk-backend) · 백엔드 개발

버스킹 장소와 공연 정보를 지도에서 탐색하고, 아티스트가 공연을 등록할 수 있는 플랫폼입니다.

- Java와 Spring Boot로 장소 조회·공연 등록 API를 제공하며, 도메인 규칙과 API·데이터 접근 코드를 계층으로 나눕니다.
- Spring Security와 OAuth 2.0·JWT로 인증을 처리하고, Redis를 토큰 관리와 캐싱에, Spring Data JPA와 QueryDSL을 데이터 조회에 사용합니다.

### [CUNi Claude Code 플러그인](https://github.com/changhyunmoon/cuni-bank-prod-v3-plugin) · AI 개발 워크플로

팀의 개발 표준을 Claude Code에서 재사용할 수 있도록 스킬과 검토 에이전트로 구성한 플러그인입니다.

- 요구사항 정리, HTML 시안, 구현 설계, 백엔드 구현을 단계로 구성하고, 설계를 승인한 뒤 구현을 진행하도록 합니다.
- 화면, 개발 표준, 백엔드 계약을 각각 검토하는 읽기 전용 에이전트를 두어 구현 결과를 별도로 확인합니다.
